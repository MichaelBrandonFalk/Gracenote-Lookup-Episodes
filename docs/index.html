Getting started

  1. Download and unzip the app, then open it.
  2. Choose an XLSX workbook or CSV and where to save results.
  3. Click Start lookup and sign in in Chrome. Programs opens automatically when you finish.
  4. Review your results and open the output file and review report. Use Clear to start over.

Settings can save sign-in details locally in your Mac’s Keychain. They are never included in workbook exports or GitHub releases. The app includes Python and needs an existing Gracenote View account. This build is ad-hoc signed; macOS may ask you to allow it in Privacy & Security on first launch.
